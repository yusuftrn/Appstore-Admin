# Changelog

## 1.0.1 — 2026-10-05

First shareable source package, with no personal account or runtime artifacts.

- Per-user storage outside the checkout; portable installed/source Codex launcher.
- Strict profile permissions, validated P-256 keys and atomic account imports.
- Atomic private outputs, constrained API/asset transport and sanitized errors.
- Dedicated screenshot uploader; legacy migration/commercial write interfaces removed.
- Offline regression tests, public file/archive allowlists and pinned GitHub CI.
- MIT license, fictional examples and installation/contribution/security documentation.
